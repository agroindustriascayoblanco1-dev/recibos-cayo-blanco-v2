ASISTENCIA

Ayuda

Si tienes problemas para consultar tu recibo, revisa estas recomendaciones o comunícate con Recursos Humanos.

¿No encuentra mi recibo?

Comprueba que seleccionaste la quincena correcta y que tu código está completo.

¿El código no funciona?

Escribe el código exactamente como aparece en tu documentación de empleado.

¿El problema continúa?

Comunícate con Recursos Humanos para recibir asistencia.

¿Qué hago si mi pago está incompleto?

Comuníquese con Recursos Humanos inmediatamente para presentar su reclamo. Recuerde que tiene un plazo máximo de 3 días después de recibir su recibo de pago para realizar el reclamo.
